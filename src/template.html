Weekly routine (2 minutes)

  1. Get the weekly files: the popcorn order Excel export and the Packing List Report PDF (both from the Booster Club database).
  2. Open this page and drop them onto the big dashed box (both at once is fine).
  3. Check the yellow warnings, if any — new teachers, kids without a homeroom, or the two files disagreeing on counts.
  4. Bag labels PDF — print on Avery 5163/5963 label sheets (2″ × 4″, 10 per sheet).
  5. Roster labels PDF — print on full-sheet 8.5″ × 11″ label stock, then make 2 vertical cuts per sheet to separate the 3 homeroom strips (staff labels follow on their own sheets, 2 across).
  6. In every print dialog choose Actual size / 100% — never “Fit to page”.

Only have one of the two files? That still works: the Excel alone makes bag labels; the packing list alone makes both (its per-room counts are the same data).

When a teacher changes

  1. Go to Roster & Settings and add, remove, or edit the teacher. Changes save automatically on this computer.
  2. To share the change with the rest of the crew, click Copy share link and text/email it, or Export settings and send the file (others use Import settings).
  3. To make the change permanent for everyone, send the exported settings.json to whoever maintains this website — they commit it and every browser picks it up automatically.

Common questions

  • A teacher shows a warning saying they’re not in the roster. A new hire, or the name is spelled differently in the export. Use the “Add to roster” button in the warning, or fix the spelling in the roster.
  • Where does my data go? Nowhere. The Excel file is read entirely inside your browser and never uploaded. Settings are saved in your browser on this computer.
  • The PDF prints misaligned. Make sure the print dialog says Actual size / 100% scale, and the label stock is Avery 5163 (or equivalent 2″ × 4″, 10-up).
  • No orders found? The export format may have changed — check the item codes and columns under Roster & Settings → Advanced.
